# 5–7 minute demo

1. Open QuoteMesh and show Arc Testnet configuration plus the honest event-derived zero/live state.
2. Connect provider A, register a profile, approve and deposit EURC.
3. Connect provider B and deposit EURC.
4. Connect the taker and create a public USDC→EURC RFQ.
5. Submit two competing firm quotes and show both reservations.
6. Compare receive amounts, rates, expiries, provider counts, fee, and external reference status.
7. Execute the winner with Arc batched approve + accept.
8. Show wallet request, transaction hash, pending state, then final settlement.
9. Open the receipt and ArcScan contract/transaction links.
10. Release the losing reservation and show available/reserved balances.
11. Show event-derived analytics and explain that App Kit reference pricing remains disabled unless
    configured.
